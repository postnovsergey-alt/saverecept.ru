# Запуск через VS Code

Коротко: открыть папку, нажать `Ctrl+Shift+B`, ответить на три вопроса. Всё.

---

## Что делает автоматика, а что придётся вам

Скрипт `setup.sh` делает сам: ставит зависимости, прогоняет тесты, генерирует
пароль и `SECRET_KEY`, подбирает свободный порт, собирает `.env`, наполняет базу
примерами, поднимает сайт. На сервере вдобавок: обследует машину, проверяет
ресурсы, ищет ключи в `.env` соседних проектов, снимает состояние соседей до и
после, держит точку отката, настраивает nginx.

Три значения он получить не может, потому что их выдают Google и Telegram только
после входа под вашей учётной записью:

| Что | Где взять | Можно пропустить? |
|---|---|---|
| Ключ Gemini | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → Create API key → **создать новый проект**, биллинг не включать | Да. Тогда страницы без разметки разберутся хуже |
| Токен Telegram-бота | [@BotFather](https://t.me/BotFather) → `/newbot` | Да. Сайт работает и без бота |
| Домен | Ваш регистратор | Да. Будет адрес вида `http://IP:порт` |

Спрашиваются они **один раз за всю жизнь проекта** — ответы ложатся в
`deploy/.secrets` и переезжают на сервер вместе с кодом. Поменять: задача
«Сменить ключи и сервер».

Ещё раз понадобитесь: ввести адрес сервера при первом деплое (тоже запоминается)
и, возможно, пароль sudo, если nginx настраивается не под sudo без пароля.

---

## Локально: одна кнопка

1. `File → Open Folder` → папка `samobranka`.
2. VS Code сам предложит поставить три расширения — согласитесь.
3. `Ctrl+Shift+B`.

Дальше скрипт всё сделает и откроет браузер. Пароль для входа напечатает в
терминале.

Если `Ctrl+Shift+B` не срабатывает: `Ctrl+Shift+P` → `Tasks: Run Task` →
«Запустить локально».

---

## На сервер: тоже одна кнопка

`Ctrl+Shift+P` → `Tasks: Run Task` → **«Развернуть на сервере»**.

Спросит адрес сервера (`sergey@203.0.113.10` или имя из вашего `~/.ssh/config`) —
и запомнит. Дальше сам: скопирует проект по SSH, передаст секреты, обследует
машину, проверит ресурсы и порты, снимет состояние musorstop и myfaza, соберёт
образ, поднимет контейнеры, дождётся ответа `/healthz`, сверит соседей и настроит
nginx. Если сайт не поднялся или у соседа что-то изменилось — откатится сам.

Дальше обновлять — задача **«Обновить на сервере»**, она уже ничего не спрашивает.

Если SSH просит пароль на каждом шагу, один раз выполните в терминале:

```bash
ssh-copy-id sergey@203.0.113.10
```

## Остальные кнопки

`Ctrl+Shift+P` → `Tasks: Run Task`:

| Задача | Зачем |
|---|---|
| **Запустить локально** | Поднять сайт на своей машине (она же `Ctrl+Shift+B`) |
| **Развернуть на сервере** | Первый деплой |
| **Обновить на сервере** | Залить свежий код и пересобрать |
| **Обследовать сервер** | Ресурсы, соседи, порты. Ничего не меняет |
| **Тесты** | 60+ проверок, около трёх секунд, сеть не нужна |
| **Разобрать ссылку** | Прогнать любой рецепт через парсер и посмотреть, что вышло |
| **Логи сервера** | Смотреть, что происходит, вживую |
| **Проверить модель** | Отвечает ли Gemini, какие модели доступны по ключу |
| **Откатить на сервере** | Вернуть предыдущую версию |
| **Сменить ключи и сервер** | Забыть сохранённые ответы |

Отладчик: `F5` → «Сайт с отладчиком» или «Бот с отладчиком». Точки останова
работают, код перезагружается на лету.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| «не удалось поставить зависимости» | Сеть или прокси. Повторите; если библиотеки уже стоят — `./setup.sh --skip-deps` |
| Деплой откатился сам | Задача «Логи сервера». Чаще всего опечатка в ключе |
| Порт занят | Скрипт подберёт другой сам; если нет — поправьте `WEB_PORT` в `.env` |
| Сборка падает по памяти | Соберите образ у себя и привезите: `docker save samobranka-web \| ssh СЕРВЕР docker load` |
| Бот молчит | «Логи сервера». Обычно неверный токен, либо аккаунт не привязан — код в профиле на сайте, отправить боту `/start КОД` |
| Рецепты разбираются криво | «Разобрать ссылку» — покажет, на каком шаге теряется |
| Модель не отвечает | «Проверить модель». Google периодически переименовывает модели |
| Надо всё вернуть | «Откатить на сервере» |

Соседей скрипты умеют только читать. Команд, которые останавливают или меняют
чужие контейнеры, в них нет.

---

## Без VS Code

Всё то же самое из терминала:

```bash
./setup.sh              # локально
./setup.sh --remote     # на сервер по SSH
./setup.sh --update     # обновить
./setup.sh --help       # остальные флаги
```
